# Beast Brawl!

Jeu de combat d'animaux en 2D, au format portrait, jouable dans le navigateur et installable sur téléphone.

Le jeu est en cours de construction : la première version jouable (V1) arrive dans ce dépôt.

## Dossier `beastbrawl/`

Ce dossier contient les images, polices, particules et boutons d'origine du jeu (menus, animaux, arène, écrans de fin).
Le jeu en fabrique des versions allégées dans `assets/`.
